# Project Structure

The SmallJ repository consists of the following folders:

## ./ (root folder)
Contains the usual Git stuff like readme, changelog, license and gitignore.
It also contains the file: Build.code-workspace.
This is the main project file for Visual Studio Code (VSCode).
It's most convenient to open VSCode with this file.
Starting Run or Debug starts the SmallJ VM, see below.

## [Documentation](Documentation.md)
This documentation. All files should be reachable through the index in Documentation.md.

## [Smalltalk](../Smalltalk)
The Smalltalk development environment.
VSCode is not needed to run SmallJ, although it is recommended for code editing.
Important files are:
- start.sh - Starts up the SmallJ system, opening the SystemBrowser. Optional argument: image file name.
- buildImage.sh - Builds a new image file from the Smalltalk sources. Argument: image file name, default image.sjim. An existing image is overwritten when the build succeeds.
- buildJar.sh - Builds smallj.jar from the VM sources. Argument: jar file name, default smallj.jar. An existing jar is overwritten when the build succeeds.
- smallj.jar - Compiled Java code for the SmallJ VM, including the libraries it uses. Generated by buildJar.sh, not stored in git.
- image.sjim - Default Smalltalk image file containing the compiled Smalltalk code. Generated by buildImage.sh, not stored in git.
	It is overwritten when the image is saved: with File > Save Image in the SystemBrowser, or when confirmed on exiting SmallJ.
	Make regular backups in case something gets broken and the system won't start anymore.

## [VM](../VM)
The SmallJ VM written in Java.
Use the VSCode Build.code-workspace in the root folder to Run or Debug it.
After the VM is altered, a new ../Smalltalk/smallj.jar file should be generated
with ../Smalltalk/buildJar.sh, or using the VSCode "Export JAR" function.

## [Extension](../Extension/README.md)
Contains an extension for VSCode for Smalltalk syntax highlighting, that should be installed locally. It's recommended to do Smalltalk development in VSCode and only use the SmallJ SystemBrowser for compilation, testing and small code edits.
